# 割草机 3D 模型查看器

在浏览器里查看割草机三维模型（新设计：下裙并入车身的一体式车身，外加一个卡扣式上盖；保留原来的前保险杠、底盘和车轮）：

- 可旋转、缩放，可一键爆炸分解为盖板、上盖、一体式车身、底盘四层；
- 上盖盖住固定车身的 14 颗螺丝，外表面没有螺丝孔；分解后能看到螺丝和它们对应的底盘螺丝柱；
- 盖板可以打开（带阻尼的鹅颈铰链，没有气撑杆），露出 STOP 键和显示屏；
- 驱动轮和万向轮始终装在底盘上，但可以自由转动；
- 原版设计保留在 `original/` 子页面，两个页面互相有链接。

## 在线版

已部署到 Vercel：<https://mower-3d-viewer.vercel.app>（公开访问，任何拿到链接的人都能打开）。

修改后重新部署：在本文件夹运行 `vercel deploy --prod`。项目已关联为 `mower-3d-viewer`，关联信息在 `.vercel/` 中。`.vercelignore` 会排除本地启动器等无关文件。

## 本地打开方式

浏览器出于安全限制，不能直接双击 `index.html` 加载模型，需要先在本机启动一个本地服务器：

| 系统 | 操作 |
| --- | --- |
| Windows | 双击 `启动查看器.bat` |
| macOS / Linux | 双击或在终端运行 `./启动查看器.sh` |
| 任意系统 | 运行 `python3 serve.py`（可加 `--port 端口号`、`--no-browser`） |

启动后会自动用默认浏览器打开查看器。地址为 `http://127.0.0.1:端口/index.html`，只在本机可访问。关闭命令窗口即可退出。

运行需要：

- Python 3（用于本地服务器）；
- 支持 WebGL 的现代浏览器，例如 Chrome、Edge、Firefox 或 Safari；
- 联网：首次打开需要联网，从 cdn.jsdelivr.net 加载 three.js。模型在本地，约 36 MB。

## 功能

- **视角**
  - 左键拖动旋转，滚轮缩放，右键平移；
  - 一键切换轴测、正面、背面、左侧、右侧、俯视（车头朝上）；
  - 自动旋转；
  - 截图（PNG）。
- **充电座**
  - 打开页面时割草机停在充电座上，车头的两个开口套在充电座立柱的两根充电针上。
  - 点“驶离充电座”，割草机自动倒车离开：驱动轮按行驶距离转动，万向轮转到跟随方向，车身沿底板边缘落到地面。再点一次（“返回充电座”）开回原位。
  - 在“显示”里可以隐藏充电座，隐藏后割草机直接停在地面上。
- **盖板**
  - 点“打开盖板”或拖动滑块，盖板绕后部铰链翻开，最大 65°。铰链带阻尼，没有气撑杆。
  - 盖板下面是 STOP 键和显示屏。分解状态下盖板保持合上。
- **爆炸视图**
  - 滑块可精细调节，也可以点“展开分解”一键动画；
  - 盖板、上盖、一体式车身依次升高，完全分开；底盘连同前保险杠、控制面板、驱动轮、万向轮保持原位；
  - 分解后，橙色细线把车身台面上的 14 颗螺丝和底盘上的螺丝柱一一连起来，蓝色细线是从底部拧入的 5 颗螺丝；
  - 镜头会自动拉远，各层旁边显示名称。
- **车轮**
  - 在模型上按住驱动轮拖动即可转动；按住万向轮拖动可绕竖直轴转向。万向轮带有转向叉，转向时一起转。
  - 只有在画面中能看到的轮子才能被拖动，被外壳挡住时拖动会旋转视角。
  - 万向轮在车尾底部。打开“透视外壳”，或点击“万向轮”标注，即可看清并拖动它。
  - 滑块可精确设置：转角为正表示向前滚动，万向轮朝向 0° 表示跟随行驶方向。
  - “行驶演示”中，驱动轮向前滚动，万向轮自动转到跟随方向。
- **配色方案**：共 10 套方案，点击面板中的色块切换，默认是银箭（与渲染图一致）。
  - 每套方案同时改变机身与盖板、黑色顶板和下裙带、饰线和轮毂灯环的颜色；底盘、前保险杠和 STOP 键保持原色。
  - 色块左上半为机身颜色，右下半为顶板颜色，中间的斜带为饰线颜色，内圈为轮毂灯环颜色。
  - 配色数据在 `models/palettes.json`（`body`、`deck`、`accent`、`ring`），可直接修改或增删方案。
- **部件标注**
  - 13 个编号标注，带引线。点击后显示说明，并转到合适的视角。
  - 被遮挡的标注会自动隐藏。
  - 标注的部件包括：翻盖、STOP 停止键、显示屏、摄像头模组、左右 LED 前灯、充电口、尾灯与饰线、卡扣式上盖、隐藏的螺丝、驱动轮、万向轮、充电座。
  - 点 STOP 键或显示屏的标注会自动打开盖板；点“隐藏的螺丝”会自动展开分解；停在充电座上时点车头的标注，割草机会先倒车驶离，以免被充电柱挡住。
- **显示开关**
  - 可以单独隐藏盖板、上盖、车身、前保险杠、底盘、充电座；只隐藏盖板和上盖，就能从上面直接看到台面上的螺丝；
  - 可以开启“透视外壳”。
- **其他**：支持手机（底部抽屉式面板）和深色模式。

## 文件

```
index.html / style.css / app.js   查看器程序（three.js r160）
artifact.html                      网页托管版本的页面（模型以 base64 文本分块加载）
models/body.glb                    一体式车身：机身与下裙、摄像头模组、充电口、上盖下面的台面、14 颗螺丝、底部螺丝柱和尾部卡钩
models/cover.glb                   卡扣式上盖：车顶与肩部、内侧卡脚、盖板下的槽体与密封圈
models/lid.glb                     盖板：面板、内衬、鹅颈铰链臂、锁扣
models/lower.glb                   前保险杠（沿用原模型）及其顶部封板
models/panel.glb                   控制面板：STOP 键与显示屏（固定在底盘上）
models/base.glb                    底盘 + 两个驱动轮 + 两个万向轮（带转轴信息）
models/dock.glb                    充电座（底板、立柱、两根充电针）
models/design.json                 盖板铰链轴位置、开启角度、底盘上各固定点的位置
models/dock_profile.json           充电座底板高度曲线（驶离动画用）
models/hotspots.json               部件标注的位置与说明
models/palettes.json               配色方案
models/rig.json                    车轮转轴、万向轮转向轴参数
original/                          原版设计的查看器（顶壳 + 中层壳体；底盘和充电座与新版共用）
serve.py / 启动查看器.*            本地启动器
```

新设计的五个 GLB（body、cover、lid、lower、panel）由 `scripts/export_design_web.py` 从设计生成器的输出导出。分解视图里的引导线由查看器程序按 `design.json` 里的固定点位置生成。

GLB 文件是标准 glTF 2.0 格式，也可以导入 Blender、Unity、Unreal 等软件。坐标单位是米，+Y 朝上，+X 指向车头。

`base.glb` 的节点结构如下：

- `Base`
  - `Chassis`
  - `Wheel_L` / `Wheel_R`：节点原点在轮轴中心，`extras.axis` 为转轴方向。
  - `CasterSwivel_L` / `CasterSwivel_R`：节点原点在转向轴上，绕竖直轴旋转。
    - `Caster_L` / `Caster_R`：原点在轮心，`extras.axis` 为滚动轴。
